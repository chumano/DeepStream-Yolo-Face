## Troubleshooting: ldconfig Warning

If you encounter this warning when running `ldconfig`:
```
/sbin/ldconfig.real: /usr/lib/wsl/drivers/nv_dispsi.inf_amd64_d5dc244a1dfc4e1d/libnvidia-ml.so.1 is not a symbolic link
```

This is a WSL2-specific warning related to NVIDIA drivers. It's safe to ignore, but you can fix it:

```bash
# in wsl
vi /etc/wsl.conf
# add the following lines
[automount]
ldconfig = false
```
